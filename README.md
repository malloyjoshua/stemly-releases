# Stemly releases

Builds and the update feed for **Stemly**, a Mac app that turns any song into a multitrack your band can rehearse with. No source code lives here.

**Download:** [Stemly.dmg](https://github.com/malloyjoshua/stemly-releases/releases/download/channel/Stemly.dmg) (Mac with Apple silicon, macOS 14 or later)

Installed copies update themselves from `appcast.xml`.
